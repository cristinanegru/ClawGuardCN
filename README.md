# ClawGuardCN
ClawGuardCN is an OpenClaw-powered AI server assistant built to monitor and recover Apache web servers running on AWS EC2.

The project started as a student idea after dealing with enough confusing Linux errors to emotionally age about 12 years in one semester.

Instead of showing boring technical messages nobody understands at 2am, ClawGuardCN explains server problems in a more user-friendly, funny, and easy-to-understand way while still helping recover the service automatically.

## What ClawGuardCN can do

- Monitor Apache server health
- Detect crashes and failed services
- Read and analyse Apache error logs
- Restart Apache automatically
- Send updates through Telegram
- Use OpenClaw skills for AI-powered automation
- Run on AWS EC2 using Ubuntu Linux

## Technologies used

- OpenClaw
- Python
- Apache2
- AWS EC2
- Ubuntu Linux
- Telegram Bot API

## Example workflow

1. Apache suddenly stops responding
2. ClawGuardCN detects the problem
3. OpenClaw analyses Apache logs
4. The assistant explains what happened
5. Apache is restarted automatically
6. Telegram receives a recovery update

## Example ClawGuardCN messages

When Apache crashes:

> "Apache has entered its emotional support phase and stopped responding.
> The server is currently behaving like a student before assignment deadline night.
> Checking logs before the situation becomes a full IT disaster."

When the server recovers:

> "Apache survived the breakdown and is back online.
> Website visitors can continue pretending nothing happened.
> Crisis avoided. Coffee levels stabilising."

## Project goal

The goal of the project was to create something that feels more like a real AI assistant instead of just another monitoring script full of unreadable Linux errors.

ClawGuardCN combines OpenClaw automation, Python scripting, AWS infrastructure, and Telegram integration to create a more interactive and user-friendly server recovery system.
